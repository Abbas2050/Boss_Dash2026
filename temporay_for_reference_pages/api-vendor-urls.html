API Vendor URLs

Override the Live / Demo base URLs used by env-driven vendor clients (Finalto today). Revert deletes the override and falls back to the compiled default. Super-admin only.

Effective Base URLs

Rows shown are the URL each vendor client will actually use. Default = compiled fallback (no DB row). Override = value stored in ApiVendorUrls. Edit the Url cell (double-click or press Enter), then click Save to upsert an override. Revert deletes the override and falls back to Default. Xtb / Lmax rows appear only after an override is added -- those vendors normally use the per-row Mt5Server host today.
