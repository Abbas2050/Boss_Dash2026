API Clients

Create and rotate OAuth client-credentials keys for external machine callers. Two-key graceful rotation, per-key + per-token revoke. Super-admin only.

Clients

Each client owns up to two active keys. Use Add second key for graceful rotation (both keys accept auth until the older one is revoked). Regenerate mints a new key and immediately revokes the older one -- breaks any deployment still using it. Revoking a client (or setting it inactive) cascades RevokedAtUtc = UtcNow onto every live token under it.
